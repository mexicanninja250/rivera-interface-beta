# Changelog

## 0.1.0-beta — 2026-10-23

Initial public beta of Rivera Interface: a Home launcher with cached app tiles, HDMI logos, public show cards, scenic motion, automatic weather, Home search/keyboard, pointer controls and an optional native Scenic screensaver.

The 1.2-second entrance waits for steady rendering while retaining unconditional native activation. Physical power-on was confirmed smoother on the tested LG B5. The public package adds regional defaults, opt-in news, checksum-verified installation and recovery backups. Native firmware, HDMI/picture drivers and gaming settings are outside the installation scope.
