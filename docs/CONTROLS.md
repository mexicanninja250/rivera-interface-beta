# Remote controls

| Action | Control |
| --- | --- |
| Open Rivera Home | Home |
| Return temporarily to LG Home | Hold Home |
| Move between tiles | D-pad |
| Open selected app or input | OK |
| Open Control Center | Hold OK, or choose the top-right control icon |
| Browse public show cards | Up from a supported app, then Left / Right |
| Reach Home / Apps / Inputs / Search | Up to the top navigation |
| Show recent apps from Home | Back |
| Exit search / Control Center / screensaver preview | Back |
| Skip an entrance still preparing or playing | Any navigation key |

The pointer toggle changes this Home screen's small circular pointer. It does not replace the shared LG pointer in settings or third-party apps. The same scope applies to the custom keyboard.

Apps and input names come from the TV. Inputs are ordered HDMI 1, 2, 3, 4 in the public release. Recognized Xbox and PC names get matching logos; other inputs use a generic HDMI icon. Changing an input name in LG's settings changes what the launcher detects.

The app library follows a curated initial order, followed by the remaining apps. The local launcher excludes several promotion/system shortcut tiles from its own grid; those apps are not uninstalled. The inherited Glasshouse layout editor does not control every part of this custom grid.

Interface sounds use the TV's native feedback service. This beta does not apply the owner's experimental system sound overlays. The Control Center sound toggle controls Home feedback.
